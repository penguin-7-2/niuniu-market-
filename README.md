# 牛牛市場

銀河奶牛（Milky Way Idle）素材行情與歷史價格比較工具。

## 本機執行

此專案使用原生 HTML、CSS 與 JavaScript，無需安裝套件或建置。

```bash
python3 -m http.server 8080 --directory dist
```

在瀏覽器開啟 http://localhost:8080 。請透過 HTTP 伺服器開啟，以便正常讀取 JSON 資料。

## 功能

- 市場物品搜尋、專業分類與收藏
- 單品量價圖，以及最多 10 項物品的獨立比較圖
- 歷史時段、價格低中高位與成交統計
- 漲跌幅門檻掃描，收藏優先排序
- 行動裝置版面、滑動游標與瀏覽器本地狀態保存

## 專案結構與部署

`dist/` 包含網站程式、物品圖示及備援資料；可部署到靜態網站主機，網站根目錄設為 `dist/`。`.openai/hosting.json` 保留原 Sites 網站的部署設定。

行情與歷史資料由外部 API 提供，依賴服務可用性與瀏覽器跨來源存取政策；本機備援資料只供外部來源無法使用時回退。收藏與選取設定儲存在各瀏覽器，匯出程式碼不會搬移使用者的瀏覽器設定。
